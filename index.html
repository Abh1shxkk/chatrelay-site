Sync between devices

Start on one device. Pick up on the other.

Every conversation, tool call and changed file goes to storage you own, then to your other devices. Claude Code and Codex chats show up in the tool's own history list, with every path changed to the new machine. Cursor, Kiro and Antigravity chats open in ChatRelay on any device. After the first upload, only the new lines travel.

Your second device in four steps
  1. 1
    Install and pick the same storage. The same synced folder or the same private GitHub repo.
  2. 2
    Get the project folder. For example with git clone. The path may be different.
  3. 3
    Bring history to this device. Git projects are matched by their remote. Others you link once.
  4. 4
    Check the dry run, then confirm. Turn on auto-sync and it happens by itself from then on.

Storage

Your history stays where you put it.

ChatRelay has no server of its own. Pick a folder your devices can all see, or a private GitHub repository. Only compressed copies go there; the history folders of your AI tools never move.

Command line

Everything in the app, from the terminal.

Safety and privacy

We worry about your history, so you don't have to.

Your originals are never changed on upload. Every write is backed up first and shown as a dry run. If a conversation changed on both devices, you keep both. If ChatRelay sees a tool format it doesn't know, it turns writing off instead of guessing.

    FAQ

    Questions, answered.

    Something else? Check the troubleshooting guide or send an email.

    Which AI tools does it work with?

    Claude Code, Codex, Cursor, Kiro and Antigravity, in the editor and in the terminal. Every chat can be viewed, searched, summarized and synced. Claude Code and Codex chats can also be restored into the tool on your other device; Cursor, Kiro and Antigravity chats open in ChatRelay on desktop, web and phone.

    Can syncing log me out of my AI tools?

    No. ChatRelay only works with your chat history. It never reads, copies or changes the login files of Claude Code, Codex, Cursor, Kiro or Antigravity. If you get logged out, it comes from the tool itself.

    What if I continued the same chat on both devices?

    Nothing is overwritten. Your copy stays as it is and the other version is saved as a new conversation, for example "… (from DESKTOP)". Both then appear in the tool and sync to your other devices.

    My old Claude Code conversations disappeared.

    Claude Code deletes conversations older than cleanupPeriodDays (30 by default). ChatRelay can raise it for you, and anything already uploaded can be pulled back from your storage.

    Why was a Codex conversation skipped?

    ChatRelay never writes to Codex's files while Codex is running. Close the Codex CLI, VS Code panel and desktop app and pull again, or let background sync retry by itself.

    Is my code sent to an AI when I make a summary?

    Only when you ask for a summary, and only after you confirm. Keys, tokens, passwords, .env values and your "never send" list are hidden first. For client code, use a model whose provider doesn't keep data.
