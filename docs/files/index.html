Files it reads and writes

Exactly what ChatRelay touches on your PC.

WhereWhat
~/.chatrelay/config.jsonMachine name and ID, backend, links, options
~/.chatrelay/state.jsonPer-session sync bookkeeping (hashes and sizes last pushed/pulled)
~/.chatrelay/backups/Timestamped backups
~/.chatrelay/logs/chatrelay.logJSON-lines log (Logs panel, copyable error report)
~/.chatrelay/queue.jsonPushes waiting for the backend
~/.chatrelay/scan-cache.jsonScan cache (sizes, times, titles)
OS keychain, service chatrelaygithub-token, anthropic-api-key
~/.claude/projects/…Claude Code conversations (read; written on pull)
~/.claude/settings.jsonOnly for auto-sync hooks and cleanupPeriodDays (backed up first)
~/.codex/sessions/…, state_5.sqlite, session_index.jsonl, memories_1.sqlite, goals_1.sqliteCodex conversations and their index (read; written on pull, only while Codex is closed, backed up first)
<project>/.chatrelay.jsonOnly for non-git projects pushed from a project screen
<project>/HANDOFF.md, CLAUDE.md, AGENTS.md, GEMINI.mdOnly when you save a summary there
