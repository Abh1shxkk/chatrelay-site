Settings

Every setting and what it does.

SectionSettingMeaning
This machineMachine nameShown next to everything this PC uploads
Sync backendFolder / GitHubWhere history is stored; Test checks the connection
AI tools(status)Each tool: installed or not, version, format detected, restore on/off, warnings, number of conversations, context file
Automatic syncAuto-syncClaude Code hooks, Codex upload a minute after a chat goes quiet, 15-minute background sync
Automatic syncTranscript retention (cleanupPeriodDays)How long Claude Code keeps conversations before deleting them
What to syncSubagent transcripts (sidecars)Claude Code's per-session subagents/ and tool-results/ folders
What to syncProject memoryClaude Code's per-project memory folder (memory/)
What to syncSecret scan before uploadOff / Warn / Auto-redact
What to syncVersions kept (folder backend)Previous copies of each file kept by the folder backend
Encryption (GitHub)PasswordTurns on end-to-end encryption, or unlocks an encrypted history on this PC; Encrypt files stored before
Storage (GitHub)Remove old versionsShows the repository's size and deletes old versions from its history (every current conversation is kept)
SecretsGitHub token, Anthropic API key, OpenRouter API key, GitHub gist tokenStored in the OS keychain (Remove from keychain deletes one)
SummariesDefault modelModel used for summaries
Never sendListWords and values hidden from summaries and shared conversations, on top of secrets and .env values
AppearanceThemeDark / light
AboutVersion, Check for updates

The same settings from the command line: chatrelay config [key] [value], for example config machineName DESK-1, config backend.folder "G:\My Drive\chatrelay", config backend.github me/my-history, config secretScan redact.
