Overview

ChatRelay keeps your AI coding chats on all your devices and carries a project's context from one AI tool to the next. Your history goes to storage you own: a folder or a private GitHub repository. There is no ChatRelay server.

#What you can do

  • Sync between devices. Start on your desktop and pick up on your laptop, with every file path changed to the new machine. See Sync between devices.
  • Search everything. Find any prompt or answer in every project and every tool, in under a second. See Search and usage.
  • Continue in another tool. Summarize a project into a HANDOFF.md, or give the next tool the context it needs. See Summaries and handoff.
  • Read anywhere. Open your chats in the web viewer or the Android app. See Web and phone viewer.
  • Stay safe. Backups before every write, a dry run before every download, and optional end-to-end encryption. See Security.
