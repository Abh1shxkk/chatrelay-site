# Updates

How new versions arrive.

- The desktop app checks for a new version when it starts, every time its window is opened, every hour, when you come back to its window after 5 minutes or more, and when you click **Check for updates** (Settings → About, the Simple view, or the command palette). It shows a spinner while checking.
- When one is available you see **A new version is available → Update now**. The app downloads it, verifies its signature (apps only accept updates signed with the project's key), installs it in place and restarts. History and settings are kept.
- The Android app shows a notice with a link to the new APK.
